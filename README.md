# 📄 한글 HWP 저장 런처 (HwpLegacySave)

> **한글에서 문서를 저장할 때 HWPX로 전환되지 않고 HWP(`.hwp`) 형식을 유지하도록 돕는 런처입니다.** 검증된 빌드는 한글 2022 교육기관용이며, 2018·2020·2024 등 다른 버전은 구조가 맞을 때 실험 모드로 시도할 수 있습니다.

> [!IMPORTANT]
> **비공식 도구 안내**
> - 이 프로젝트는 (주)한글과컴퓨터와 **관련이 없으며**, 한컴의 승인·보증·기술 지원을 받지 않습니다.
> - "한글", "한컴", "한컴오피스" 등의 명칭과 상표는 각 권리자의 소유이며, 대상 제품을 가리키기 위해서만 사용합니다.
> - 실행 중인 한글의 저장 동작을 바꿉니다. 사용 전에 **한컴 소프트웨어 사용 계약서**와 **소속 기관의 문서 정책**에서 허용되는지 직접 확인하세요.
> - 어떠한 보증 없이 제공됩니다. 문서 손상, 호환성 문제, 계약·정책 위반 등 사용에 따른 책임은 사용자에게 있습니다. 중요한 문서는 먼저 백업하세요.

---

## 💡 왜 필요한가요?

한글 2022(특히 교육기관용 등)에서는 새 문서를 저장하거나 기존 문서를 편집 후 저장할 때 **기본 형식이 HWPX(`.hwpx`)로 자동 전환**됩니다. 일반판은 [도구] → [환경 설정] → [파일]의 **다음 형식으로 파일 저장**에서 HWP를 고르면 되므로 이 런처가 필요 없습니다. 교육기관용·공공기관용은 이 설정과 관계없이 `.hwp` 저장을 `.hwpx`로 바꿉니다. 2026년 11월부터는 공공기관용 2018~2024에도 HWPX 기본 저장이 순차 적용됐습니다([버전별 호환성](docs/VERSION-COMPATIBILITY.md)).
이로 인해 HWPX를 지원하지 않는 구버전 한글 사용자나 외부 기관과 문서를 주고받을 때 매번 파일 형식을 변경해야 하는 번거로움이 발생합니다.

**한글 HWP 저장 런처**는 번거로운 수동 변환 없이, 실행 버튼 클릭 한 번으로 **항상 기존 HWP(`.hwp`) 형식으로 저장**할 수 있도록 돕습니다.

## ✨ 주요 기능

- 📁 **기본 저장을 `.hwp`로 자동 유지**
  - 일반 저장(`Ctrl+S`) 및 [다른 이름으로 저장] 시 자동으로 HWP5(`.hwp`) 형식을 기본값으로 유지합니다.
  - HWPX 저장이 필요한 경우, 저장 창에서 파일 형식을 직접 HWPX로 선택하면 언제든 HWPX로도 저장할 수 있습니다.
- 🧩 **설치 파일을 수정하지 않는 실행 중 적용 방식**
  - PC에 설치된 한글 실행 파일(`Hwp.exe`)이나 윈도우 시스템 파일을 수정하지 않습니다.
  - 런처를 통해 켠 한글 프로세스에서만 저장 동작이 바뀌며, 한글을 닫으면 그 변경은 사라집니다.
  - 런처 설정과 실행 로그는 `%LOCALAPPDATA%\HwpSaveHook\`에 남습니다.
- 🔍 **한글 자동 탐지 & 간편 실행**
  - PC에 설치된 한글 프로그램을 자동으로 탐지하여 연결합니다. 한컴 설치 레지스트리, 문서 연결, 실행 중인 한글, 다른 드라이브의 설치 폴더까지 찾으며 2018~2024 등 버전 번호에 관계없이 동작합니다.
  - 여러 버전이 설치돼 있으면 검증된 빌드 → 적용 가능한 빌드 순으로 고르고, 다른 설치본이 있다는 것도 알려 줍니다.
  - 설치 경로가 기본값과 다르더라도 [찾아보기…] 버튼으로 한 번만 지정해 두면 이후 자동으로 기억합니다.
- 🔄 **원클릭 모드 전환 (ON / OFF 스위치)**
  - 토글 스위치 하나로 HWP 저장 유지 기능을 손쉽게 켜고 끌 수 있습니다.
  - 기능을 끄거나 시작 메뉴에서 한글을 직접 실행하면 평소의 원래 한글 동작으로 열립니다.
- ⚡ **런처 없이 바로 실행 (바탕화면 바로가기 & 한글 문서 더블클릭 연동)**
  - 매번 런처를 먼저 켤 필요 없이, 런처에서 한 번만 설정해 두면 **바탕화면 바로가기**나 **탐색기의 한글 문서 더블클릭**만으로 창 없이 곧바로 HWP 저장 모드가 적용된 한글이 열립니다.
  - 더블클릭 연동은 `.hwp`뿐 아니라 한글이 여는 `.hwpx`·`.hwt`·`.hwtx`·`.hml`·`.owpml`에도 적용됩니다. `.hwpx` 문서로 한글을 먼저 열어도 HWP 저장 모드가 적용된 한글이 떠서, 이후 더블클릭한 `.hwp` 문서도 HWP로 저장됩니다. 다른 형식 문서의 저장 결과는 바뀌지 않습니다.
  - 한컴 업데이트 등으로 연결이 풀리면 런처나 바로가기를 실행할 때 자동으로 다시 연결합니다. `.hwp` 기본 앱이 다른 프로그램으로 바뀌었으면 런처 화면에서 알려 줍니다.
  - 관리자 권한 없이 현재 사용자 계정 수준에서 등록하고 해제합니다. 파일 연결 기능은 현재 사용자 레지스트리(`HKCU`)를 변경합니다.
- 🧪 **다른 한글 버전 판정 (실험)**
  - 한글 2018·2020·2024 등 검증되지 않은 빌드도 `Hwp.exe` 구조를 읽어 적용 가능 여부를 알려 줍니다.
  - 저장 형식 변환 코드의 구조가 같으면 **검증되지 않은 한글 버전에도 시도** 스위치를 켜서 적용할 수 있습니다. 기본값은 OFF입니다.
  - `Hwp.exe`가 .NET 기반이 아닌 버전은 이 방식으로 바꿀 수 없어 일반 실행만 합니다.
- ⬆️ **서명된 자동 업데이트**
  - 시작할 때 GitHub의 업데이트 정보를 확인하고, 새 버전이 있으면 **업데이트 확인** 버튼이 **설치**로 바뀝니다.
  - 서명(ECDSA P-256)과 SHA-256이 맞는 공식 ZIP만 설치합니다. 교체 후 새 버전이 시작되지 않으면 이전 파일로 되돌립니다.
  - 설치 폴더에 쓸 수 없으면(예: `Program Files`) 릴리스 페이지를 열어 수동 업데이트를 안내합니다.
- 🚦 **중복 실행 확인 및 상태 안내**
  - [한글 열기]는 한글이 이미 켜져 있으면 새로 실행하지 않습니다. 켜져 있는 한글에 HWP 저장 모드가 적용됐는지도 알려 줍니다.
  - 시작 메뉴·작업 표시줄 등으로 HWP 저장 모드 없이 연 한글이 이미 떠 있으면, 더블클릭한 문서가 그 창으로 들어가기 전에 경고합니다. 한컴 업데이트로 빌드가 바뀌어 HWP 저장 모드를 적용할 수 없을 때도 일반 모드로 조용히 열지 않고 먼저 묻습니다.
  - 런처 화면에서 현재 기능 적용 단계(준비 완료, 적용됨, 실행 실패 등)를 직관적으로 안내합니다.

## 🚀 빠른 시작 가이드 (사용 방법)

복잡한 설정 없이 간편하게 사용할 수 있습니다.

### 1단계. 프로그램 실행
`HwpSaveHook.exe`를 실행합니다.
런처가 PC에 설치된 한글을 자동으로 찾아 파일 경로와 지원 상태를 표시합니다.

### 2단계. 'HWP 저장 유지' 확인 후 [한글 열기] 클릭
- **HWP 저장 유지** 스위치가 **ON** 상태인지 확인합니다. (기본값: ON)
- 파란색 **[한글 열기]** 버튼을 누릅니다.

### 3단계. 평소처럼 문서 작성 및 저장
한글이 열리면 평소처럼 문서를 작업하고 저장하세요.
지원 빌드에 적용된 상태라면 `.hwp` 형식이 유지됩니다. 일부 상황에서는 한글의 원래 저장 동작을 따를 수 있으므로 저장된 파일 형식을 확인하세요.

### 💡 더 편하게 쓰기 (런처 없이 바로 실행)
런처 하단의 **런처 없이 바로 실행** 영역에서 다음 두 가지 연동을 원클릭으로 켜고 끌 수 있습니다.
- **바탕화면 바로가기 [만들기]**: 바탕화면에 `한글 2022 (HWP 저장)` 아이콘을 생성합니다(이름은 기존 바로가기와 호환을 위해 유지합니다). 아이콘을 누르면 런처 창 없이 한글이 바로 열립니다.
- **`.hwp` 문서 더블클릭 자동 적용 [ON/OFF]**: 탐색기에서 `.hwp`·`.hwpx` 등 한글 문서를 더블클릭해 열 때도 자동으로 HWP 저장 모드로 실행됩니다. (이미 한글이 열려 있으면 기존 한글 창에서 문서를 바로 열어줍니다.)

> ⚠️ **시작 메뉴·작업 표시줄의 한글 아이콘으로 연 한글에는 HWP 저장 모드가 적용되지 않습니다.** 이 창이 떠 있는 동안 더블클릭한 `.hwp` 문서도 그 창에서 열리기 때문에 저장하면 HWPX가 될 수 있습니다. 이 경우 경고 창이 뜹니다. 작업 표시줄에는 한글 대신 바탕화면의 `한글 2022 (HWP 저장)` 바로가기를 고정해 두세요.

## 🖥️ 화면 및 상태 안내

런처 하단의 알림창에서 현재 동작 상태를 쉽게 확인할 수 있습니다.

| 상태 안내 문구 | 설명 |
|---|---|
| **HWP 저장 요청이 접수됐습니다** | 준비가 완료되었습니다. 한글이 실행된 후 첫 저장 시 기능이 최종 적용됩니다. |
| **HWP 저장 모드가 적용됐습니다** | 현재 실행 중인 한글에 HWP 유지 기능이 성공적으로 적용되어 안전하게 동작 중입니다. |
| **실행 중인 한글을 종료한 뒤 다시 시도하세요** | 한글이 이미 실행 중입니다. 열려 있는 한글을 저장 후 닫은 뒤 런처에서 다시 열어주세요. |
| **HWP 저장 모드로 실행 중인 한글이 있습니다** | 이미 떠 있는 한글에 HWP 저장 모드가 적용돼 있습니다. 그 창에서 문서를 열고 저장하면 됩니다. |
| **HWP 저장 모드 없이 실행된 한글이 있습니다** | 시작 메뉴 등으로 연 한글이 떠 있습니다. 그 창에서 저장하면 HWPX가 될 수 있으니 저장하고 모두 닫은 뒤 다시 여세요. |
| **HWP 저장 모드 적용에 실패했습니다** | 적용 과정에 문제가 발생했습니다. 한글을 닫고 다시 시도하거나 [실행 로그 열기]로 원인을 확인할 수 있습니다. |

> 📌 **한글을 자동으로 찾지 못할 때**:
> **[찾아보기…]** 버튼을 눌러 한글 설치 폴더 내의 `Hwp.exe`를 직접 선택해 주시면 다음 실행부터 자동으로 기억합니다.

## ❓ 자주 묻는 질문 (FAQ)

<details>
<summary><b>Q. 한글 프로그램 파일이 변경되거나 보안상 문제는 없나요?</b></summary>

설치된 한글 실행 파일과 라이브러리는 수정하지 않으며 디지털 서명도 그대로입니다. 
런처로 띄운 한글 프로세스에 모듈(DLL)을 연결해, 메모리에서 저장 형식 변환을 건너뛰도록 작동합니다. 이 변경은 한글을 종료하면 사라집니다.

다만 보안상 문제가 전혀 없다고 보증하지는 않습니다. 다른 프로세스의 동작을 바꾸는 방식이라 백신이나 기관 보안 프로그램이 차단·경고할 수 있습니다.
</details>

<details>
<summary><b>Q. HWPX 형식으로 저장하고 싶을 때는 어떻게 하나요?</b></summary>

한글의 [다른 이름으로 저장] 창에서 파일 형식을 직접 **한컴오피스 한글 문서(*.hwpx)**로 선택하시면 정상적으로 HWPX 형식으로 저장됩니다.
</details>

<details>
<summary><b>Q. 원래 한글 기본 동작으로 되돌리려면 어떻게 하나요?</b></summary>

- 런처에서 **HWP 저장 유지** 스위치를 **OFF**로 바꾸면 [한글 열기], 바탕화면 바로가기, `.hwp` 더블클릭 모두 원래 한글 동작으로 열립니다.
- 한글 문서 더블클릭 연동을 완전히 해제하고 싶다면 **`.hwp` 문서 더블클릭 자동 적용** 스위치를 **OFF**로 끄면 연동한 모든 한글 문서 형식을 저장해 둔 이전 파일 연결 설정으로 되돌립니다.
- 런처를 켜지 않고 윈도우 시작 메뉴의 한글 아이콘으로 직접 실행해도 항상 원래 한글 동작 그대로 열립니다.
</details>

<details>
<summary><b>Q. 지원하는 한글 버전은 무엇인가요?</b></summary>

실기 검증한 빌드는 **한글 2022 교육기관용(12.0.0.4645)** x86 하나입니다.

다른 빌드는 런처가 `Hwp.exe` 구조를 읽어 아래처럼 안내합니다.

| 화면 안내 | 의미 |
|---|---|
| 검증된 빌드 · HWP 저장 사용 가능 | 그대로 사용할 수 있습니다. |
| 검증되지 않은 빌드입니다. 구조가 같아 … 켜면 적용할 수 있습니다 | 한글 2018·2020·2024 등에서 변환 코드 구조가 같습니다. **검증되지 않은 한글 버전에도 시도**를 켜면 실험적으로 적용합니다. 저장한 파일 형식을 꼭 확인하세요. |
| .NET 기반이 아니어서 이 방식으로 바꿀 수 없습니다 | 해당 버전은 지원할 수 없습니다. OFF로 일반 실행하세요. |
| 저장 형식 변환 코드를 찾지 못해 지원하지 않습니다 | 구조가 달라 적용하지 않습니다. |

다른 버전에서 정상 동작을 확인하셨다면 `hwp-save-hook inspect` 결과를 이슈로 알려 주세요. 검증 목록에 추가하는 방법은 [버전별 호환성](docs/VERSION-COMPATIBILITY.md)에 있습니다.
</details>

<details>
<summary><b>Q. 업데이트는 어떻게 하나요? 인터넷에 무엇을 보내나요?</b></summary>

런처를 열 때 `raw.githubusercontent.com`에서 `updates/latest.json`(수 KB)을 받아 새 버전이 있는지 확인합니다. 사용자 정보나 문서 정보는 보내지 않으며, 요청에는 `HwpSaveHook-Updater` User-Agent만 붙습니다. 확인에 실패해도(오프라인 등) 런처는 평소처럼 동작합니다.

설치를 누르면 GitHub 릴리스의 ZIP을 받아 서명·해시를 확인한 뒤, 런처를 잠시 닫고 파일을 교체한 다음 다시 엽니다. 한글이 실행 중이면 설치하지 않습니다. v1.1.1 이하에는 업데이터가 없어 v1.2.1(업데이터가 들어간 첫 릴리스)은 한 번 직접 내려받아 교체해야 합니다.
</details>
